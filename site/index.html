Install

  1. Close Project P.I.T.T. The installer won't run while the game is open.
  2. Download the zip from the button above and unzip it anywhere, like your Desktop.
  3. Double-click Install.bat It finds the game through Steam on any drive. If Windows SmartScreen pops up, choose More info then Run anyway.
  4. Launch the game from Steam as usual. A Multiplayer button now sits under Play.

Everyone in a lobby needs the same mod version. Lobbies on a different version show up greyed out.

Play together

Hosting

Multiplayer▸Host▸Start

Your lobby shows everyone who joined. Use Invite friends to send Steam invites, then press Start when the crew is in. Saves stay on the host's PC.

Joining

Multiplayer▸Join▸pick a lobby

The list shows your friends' open lobbies and how many players are in each. You can also accept a Steam invite or click Join Game on a friend in Steam.

FAQ

How do I uninstall it?

Double-click Uninstall.bat in the folder you unzipped. It removes only what the installer added and restores anything it changed.

Will it touch my saves?

No. The mod never writes the game's save files. In multiplayer, only the host's game saves the world.

Does "Verify integrity of game files" remove it?

No, Steam leaves the mod's files alone. To remove the mod, use Uninstall.bat.

Something broke. What do I send?

Open an issue on GitHub and attach your log: %APPDATA%\Godot\app_userdata\Project P.I.T.T\pittapi\pittapi.log

Do my friends need the mod too?

Yes. Everyone needs the same version installed, and everyone needs to own Project P.I.T.T. on Steam.
